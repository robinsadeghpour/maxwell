Every Claude Code session, sorted by what it needs from you

A Mac app for running many Claude Code sessions at once. The ones waiting on you come first, across every project and account. None is called safe to close until Maxwell can prove it.

Download for macOS View on GitHub

Free and open source · MIT · macOS 14+ on Apple Silicon

One window for every session

The Claude session in the middle, everything else you have running on the left, usage for each account along the bottom.

Sorted by what they need

Each session is in exactly one group. You only have to look at the first two.

Needs you

Asked a question or wants a permission.

Your turn

Finished its reply and is waiting.

Working

Still running.

Limited

Hit a usage limit.

Safe to close

Done, with proof.

Idle

Quiet for a day.

Notifications

A Mac notification when a session asks you something. ⌘J opens the next one.

Every account

5-hour and weekly usage per account. ⌘T starts a session on the one with the most left.

Search

⌘P finds a session by title, project, branch, account, last message or a file it touched.

The real session

The middle pane is the Claude session itself, in a Ghostty terminal. Closing Maxwell doesn't stop it.

Files beside it

Markdown files a session writes open rendered on the right.

Projects

A rail on the left switches projects. Pin the ones you use; the rest show up when they need you.

Safe to close

A session is only marked safe when every check passes. If a check can't run, it isn't safe.

  • Nothing is running, including background tasks and subagents.
  • Its last reply ends with "Safe to close" and asks nothing.
  • Git is clean and pushed, and the PR is merged.
  • Haiku reads the last message and confirms it's finished.
  • Closing runs claude stop. You can undo it or reopen it later.

    

  


  

    

      
Install
Everything stays on your Mac. Nothing is sent anywhere except the Haiku reads, through your own Claude account.

      

        
1
Download
Open the DMG and drag Maxwell to Applications, or run brew install --cask robinsadeghpour/maxwell/maxwell.

        
2
Set it up
Maxwell lists what's left, one button each. Your settings are backed up first.

        
3
Add accounts
One line per account in ~/.config/maxwell/config.
