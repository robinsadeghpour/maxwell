Safe to close

Closing a session that's still working, or waiting on you, costs you work. So Maxwell only calls a session safe when it can prove it.

#The rules

  1. Unknown is never safe. If Maxwell can't check something, the session isn't safe.
  2. It needs proof of a finished task. Nothing is running, including background tasks and subagents. Its last message asks nothing and offers nothing. Git is clean and pushed, and the PR is merged if there is one.
  3. A final read by a small model. Only for sessions that passed everything else, Haiku reads the last message once and has to answer finished. Each read costs about $0.0002.
  4. You see the evidence. Each safe session lists every check and where its result came from.
  5. Checked again at the moment of closing. If anything changed, that session is skipped.
  6. Closing never deletes. Maxwell only runs claude stop, which keeps the conversation.
  7. "Not safe" teaches it. Mark a wrong call and it becomes a test case, so the mistake can't repeat.

#The status line

Every new session is asked to end each reply with one line: Safe to close, Not done or Needs you, and a few words. Maxwell shows it on the row. Needs you moves the session to Needs you, and Not done keeps it out of Safe to close. A Safe to close line is one more piece of evidence, never enough alone. wrap-line = off turns it off.

#Close sessions

⇧⌘X closes every safe session. It shows the list and asks first. ⇧⌘⌫ closes the selected session: at once when it's safe, otherwise after saying what's still open.

⌘Z undoes a close for 10 seconds. Anything closed in the last 7 days can be reopened from Recently closed.

#Plugin checks

Plugins can add checks, and the same rules apply. A plugin that isn't running can't vouch, so its checks turn unknown. A check from before the session's last activity doesn't count. The Linear plugin adds "Linear ticket done". The Slack plugin adds "Replied on Slack" to sessions started from a message.

#Tune it

judge = on        # off skips the model read, so nothing is ever safe

Run Maxwell state in a terminal to audit every session and see which check holds each one back.
