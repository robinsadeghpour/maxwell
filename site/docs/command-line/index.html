Command line

The Maxwell binary answers a few commands in a terminal, for auditing and undoing.

Run them with the binary inside the app:

/Applications/Maxwell.app/Contents/MacOS/Maxwell state
CommandWhat it does
stateEvery session by group, and for each stopped one, every Safe to close check with its result and source
titlesEvery session's title and where it came from
accountsThe accounts Maxwell knows and their config folders
install-hooksThe same as Maxwell › Install Hooks
uninstall-hooksRestores each account's settings from the backup
