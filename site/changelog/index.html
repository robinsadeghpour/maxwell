Nov 18, 2026v0.1.63

Settings › Phone

Maxwell can now pair with a phone. Settings › Phone shows a code to scan; once a phone is paired, it sees the same sessions as the Mac, follows a session's conversation and terminal, answers permission prompts, opens artifacts in the right account, starts, closes and moves sessions, and gets a push when a session needs you while you're away from the Mac.

The phone and the Mac meet on a small relay and everything between them is end-to-end encrypted; the relay forwards bytes it can't read. Maxwell connects to it only while a phone is paired or a code is showing, and phone-relay = off turns it off. The iPhone app is in private testing. How it works.

Nov 18, 2026v0.1.62

/resume works across folders

Type /resume in a session and pick a conversation from another folder, and Maxwell now opens it. Claude Code can't switch folders inside a running session, so it only prints a cd … && claude --resume … command to paste into a terminal. Maxwell reads that command off the session and runs it: the conversation resumes in its own folder as a background session and opens in the pane.

If the session you typed /resume in has no reply yet, Maxwell closes it, since it was only opened to get to the other one. A conversation Maxwell already lists is opened instead of started twice.

Cloud sessions

Maxwell now works with Claude Code sessions that run on Anthropic's cloud machines. They sit in the same groups as your other sessions, marked cloud, and a question from one shows in Needs you with a notification. Opening one shows its claude.ai page in the middle pane, signed in to its account.

⌥⌘N starts a session in the cloud from a project and a task. With Cloud picked, the new-session panel says what won't go along, such as commits that aren't pushed. ⌥⌘↑ sends a session from your Mac to the cloud: it commits, pushes and writes a brief, and a cloud session continues from there. ⌥⌘↓ brings a cloud session back into a fresh worktree. How cloud sessions work.

Nov 15, 2026v0.1.14

Plugins: Linear and Slack

Maxwell now has plugins, and two ship with it. They live in one Plugins panel (⌥⌘6) with a tab each, and dock left, right or bottom like every other panel.

Linear

Each session's ticket and status show on its row, read from the branch name or the transcript. "Linear ticket done" joins the Safe to close checks, so a session isn't safe until its ticket is. When the work moves, Linear suggests the matching ticket move: In Progress when a session starts, a comment when the PR opens, Done when it merges.

Slack

Slack lists who is waiting on a reply from you: DMs, mentions and threads, with bugs and customers first. It only reads. Start Session starts a Claude session from a message and links the two, and that session isn't safe to close until you've replied in the thread.

Write your own

A plugin is a folder with a manifest and a program in any language. It talks to Maxwell with JSON lines over stdin and stdout, and Maxwell draws its panels with its own components, so every plugin looks native in every theme. A plugin that crashes is shown as stopped with a Restart button. It can't take Maxwell down. Read the plugin guide.

Fixes and improvements

  • Plugin secrets live in the Keychain and only the plugin that declared them can read them

Nov 14, 2026v0.1.12

Maxwell is public

Maxwell is a native Mac app for running many Claude Code sessions at once. It reads what every session is doing, sorts them by what they need from you, and only calls a session safe to close when it can prove it.

The first public release covers the core: the six groups, projects on a Dock-style rail, the real Claude session attached in a Ghostty terminal, Markdown files rendered beside it, usage for every account, and search across everything with ⌘P.

Safe to close means safe

Unknown is never safe. A session needs proof that its task is finished: nothing running, two quiet hours, a last message that asks nothing, git clean and pushed, the PR merged. Then Haiku reads the last message once and has to answer finished. Closing only runs claude stop, with Undo for 10 seconds. How Safe to close works.

Fixes and improvements

  • Updates come straight from GitHub's public releases. No GitHub login needed
  • Needs a Mac with Apple silicon and macOS 14 or later
  • Free and open source under the MIT licence
