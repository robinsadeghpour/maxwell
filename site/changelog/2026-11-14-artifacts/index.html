Artifacts open beside the session

When a session publishes a claude.ai artifact, it now opens on the right, next to the session that made it, signed in as that session's account. Publishing again reloads it in place, even when it's pinned.

Each account signs in once, on claude.ai's own page, and keeps its own login. Maxwell already knows which account every session runs on, so it always picks the right one. ⇧⌘O opens the artifact in that account's browser profile or container instead.

Bring terminal sessions into Maxwell

A session running in another terminal now has a Bring into Maxwell button. Maxwell ends the terminal's process and resumes the same conversation as a background session, with the same id, account, folder and permission mode. A session in the middle of a turn moves when the turn ends. Session › Bring Terminal Sessions into Maxwell… moves all of them at once.

Fixes and improvements

  • Close any session from its right-click menu. If it isn't safe yet, Maxwell says what's still open and asks first
  • Sessions named only by a slug or their first words get a readable name from Haiku, once, for about $0.0003
  • Right-click a session to rename it. Your name always wins
