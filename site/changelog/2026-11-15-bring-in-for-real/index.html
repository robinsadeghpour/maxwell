Nov 15, 2026v0.1.24 – v0.1.25

Terminal sessions move into Maxwell

Bring into Maxwell now ends the session in your terminal before it continues in Maxwell. Recent Claude Code versions stopped recording which process runs a terminal session, so Maxwell couldn't find it, and the session carried on in Warp or Terminal while a second copy started in Maxwell. Maxwell's hook now notes the process itself.

When Claude Code hasn't been told it may work in a folder, ⌘T and New Session now ask Let Claude work in this folder?, the same question Claude asks in a terminal. Click Trust Folder and the session starts.

Slack and Linear now start off. Turn them on in Settings › Plugins when you want them.

Fixes and improvements

  • Fixed Bring into Maxwell failing for sessions started in the home folder
  • Fixed the "Not trusted on default yet" dead end on ⌘ T
  • Messages name the account only when you have more than one
  • When several Claude sessions run in the same folder and Maxwell can't tell which one to move, it says so and leaves them running
  • Maxwell is now signed and notarized by Apple, so the download opens without the "could not verify" warning. Plugin keys ask for Keychain access once more after this update
OlderQuieter plugin lists and a tidier SettingsNewerPick a sound for each notification
