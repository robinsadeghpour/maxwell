Nov 15, 2026v0.1.29

Set up in one place, and All projects adds up

With no session open, Maxwell now starts with Set up Maxwell. It checks four things: that Claude Code is installed, the session hooks, a claude.ai sign-in for each account so artifacts open beside the session, and notifications. Each step that's left has one button. Steps tick themselves off as you go, and the list goes away once everything is done. Hide puts it away early. Everything in it is also in Settings.

All projects now lists every session, not only the ones waiting on you. Its count matches the bottom bar. Idle and Recently closed stay folded.

A new Maxwell often finds sessions from days ago that are still running. They fold into Idle, and its new stop all stops the background ones. Conversations are kept, and Undo brings them back. Rows of sessions running in another terminal now say so.

Fixes and improvements

  • A question nobody answered for 3 days now folds into Idle instead of staying in Needs you
  • The Dock badge now counts the Needs you group
  • Maxwell now installs with Homebrew: brew install --cask robinsadeghpour/maxwell/maxwell
